# Power BI Sales Dashboard

## Overview

This project is an interactive Sales Analytics Dashboard
developed using Microsoft Power BI.

The dashboard analyzes sales, profit, customers, products,
regions and business trends using a 10,000-record sales dataset.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Dashboard Pages

### Page 1 – Executive Overview
- Total Sales
- Total Profit
- Total Orders
- Sales Growth
- Profit Margin
- Sales by Category
- Sales by Region
- Monthly Sales Trend

### Page 2 – Sales Analysis
- Sales by State
- Sales by City
- Sales by Category
- Sales Channel Analysis
- Top Products

### Page 3 – Profit Analysis
- Profit by Category
- Profit by Region
- Profit by Sales Channel
- Profit Margin
- Sales vs Profit

### Page 4 – Customer Analysis
- Customer Count
- Sales by Customer Segment
- Profit by Customer Segment
- Sales by City
- Sales by State

### Page 5 – Trends & Forecast
- Total Sales Trend
- Top Products
- Average Order Value
- Maximum Sales

## Key Features

- Interactive dashboard
- KPI cards
- Slicers and filters
- DAX measures
- Bookmark functionality
- Selection pane
- Page navigation
- Interactive visualizations

## Dataset

The dashboard is created using a 10,000-record
sales dataset containing information about orders,
customers, products, regions, sales and profit.
